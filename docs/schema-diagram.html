ya migrado (000001–000017) se agrega en Módulo 1 (000018)

fuel_indexes es la única tabla sin company_id: es un catálogo de referencia global (precios de combustible), no dato de una empresa — por eso no tiene flecha de relación en el diagrama, se cruza en la lógica de aplicación por fuel_type/región, no por llave foránea.

Qué agrega exactamente el Módulo 1

  1. ALTER TABLE invoices ADD COLUMN bank_account_id UUID REFERENCES bank_accounts(id) — nullable, se llena al registrar el pago.
  2. ALTER TABLE expenses ADD COLUMN bank_account_id UUID REFERENCES bank_accounts(id) — mismo criterio.
  3. Tabla nueva cash_flow_projections (company_id, projected_date, projected_balance) — snapshot diario que llena el batch job de proyección a 30/60 días.
